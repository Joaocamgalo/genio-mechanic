# Instruções de atualização

1. Faça uma cópia de segurança do projeto atual.
2. Copie os quatro arquivos da pasta `arquivos_para_substituir` para os mesmos caminhos dentro do seu projeto.
3. Confirme a substituição dos arquivos existentes.
4. Em um terminal separado, execute `npm run build`.
5. Depois execute `npm run dev` e abra a tela Visão Geral.

Não é necessário executar SQL ou alterar o Supabase.
