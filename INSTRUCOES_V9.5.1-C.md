# Instalação — ControlMaq V9.5.1-C

## Forma recomendada

1. Faça backup do projeto atual.
2. Extraia este ZIP em uma nova pasta.
3. Copie o arquivo `.env` ou `.env.local` do projeto atual, caso exista.
4. Abra a nova pasta no StackBlitz/Bolt ou VS Code.
5. Execute `npm install`.
6. Execute `npm run build`.
7. Execute `npm run dev`.

Nenhum comando SQL é necessário.

## Validação visual

Na tela **Visão geral**, confirme:

- Central de Atenção abaixo dos KPIs;
- prioridades separadas por grupo;
- botão para ver todas quando houver mais de cinco;
- abertura direta dos chamados;
- navegação para histórico da máquina;
- acesso às pendências de horímetro.
