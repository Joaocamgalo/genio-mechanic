# Instruções de atualização — V9.5.1-A

Esta entrega contém o projeto completo. A forma mais segura é manter a versão anterior como backup e usar esta pasta como uma nova versão do projeto.

1. Faça uma cópia da pasta atual do ControlMaq.
2. Extraia este ZIP em uma nova pasta.
3. Copie o arquivo `.env` ou `.env.local` da versão atual para a nova pasta, caso ele exista.
4. Abra a nova pasta no VS Code.
5. Abra o terminal nessa pasta.
6. Execute `npm install`.
7. Execute `npm run dev` para testar localmente.
8. Execute `npm run build` antes de publicar.

Não é necessário substituir arquivos individualmente. O `App.tsx` e as telas atuais foram preservados.
